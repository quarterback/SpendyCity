METHODOLOGY · ISSUE 01

How this site was built

A note on what is modeled, what is not, and the editorial choices behind the chart language.

What the figures are

Every number on this site — year-end balances, obligated amounts, promise-vs-delivered cycles, drift indices, reserve series — is modeled. They are constructed reconstructions designed to illustrate a structural pattern that has been repeatedly documented across audits, council resolutions, and bureau reporting on Portland and Multnomah County's voter-restricted funds.

This site is a journalistic visualization, not a published ledger. The corpus task that ships behind it (Task #4) will produce an audited monthly figure set; this site is structured so that swapping the modeled series for the audited series is a one-file edit per fund.

Why model it at all

The actual figures are not centralized. Each fund's record is spread across an enabling code, a ballot pamphlet, an annual financial report, multiple bureau memos, and an audit-trail of council actions. There is no single dashboard that shows the seven of them on the same axes. This site is, in effect, the dashboard that should already exist.

Modeling choices

  • Cash series. Each fund's year-end balance is generated from a starting inflow, a yearly inflow growth rate, and a year-by-year spend ratio that ramps up after enactment. Obligated share is held at a fund-specific fraction of the balance.
  • Audit events. Each annotation maps to a real category of finding (collection-cost overrun, scope expansion, surplus carryover, compliance-rate gap) but the year-by-year placement is illustrative. Source lines name the institutional source (auditor, council, bureau) rather than a specific document number.
  • Drift index. A 0–100 score where 100 means every dollar is being used in a way that maps to the original ballot text. It is constructed by reading post-enactment ordinances and resolutions against the ballot text, scoring how much of the affected balance moved off baseline, and compounding forward.
  • Promise vs. delivered. Promised dollars are those committed in a published bureau plan; delivered dollars are what shipped against the plan. The gap is the structural under-spend that becomes carryover.

Tech stack

This site is published as a static SvelteKit build with D3 for charts and scrollama for chart-driven scroll. The agent endpoint is a single serverless route in the API server that streams Anthropic's Claude (Sonnet generation) over Server-Sent Events. There is no database; fund records live in TypeScript modules.

Type ·Fraunces (display + body), JetBrains Mono (kicker, axis, annotation).

Editorial choices

Charts are wide and prose is narrow on purpose. Margin notes carry the auxiliary read. Audit annotations break out of the chart frame so they are read as commentary on the data, not as the data itself. Color is restrained: a single accent on the share of the carry that has been made movable.

There are no calls to action on this site. There are no advocacy blocks. The tone is that of a public-finance officer writing a memo, not that of a campaigner.

Provenance markers

Every chart frame names its source line. Modeled charts say "Modeled reconstruction (PDX Spend)". When the audited series is wired in, that line will change to name the financial document the figure was pulled from.

What you can do with this

Each chart has download buttons for both the rendered PNG and the underlying CSV. The dashboard view has a copy-to-clipboard embed snippet. The whole site is open and reproducible.
